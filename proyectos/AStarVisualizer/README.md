# Visualizador del Algoritmo A*

Proyecto desarrollado en Python y Pygame para visualizar el funcionamiento del algoritmo de búsqueda A*.

## Características

- Selección de nodo inicial.
- Selección de nodo final.
- Creación de obstáculos.
- Búsqueda del camino óptimo.
- Visualización de nodos abiertos y cerrados.
- Reconstrucción del camino encontrado.

## Controles

### Mouse izquierdo

- Primer click → Inicio.
- Segundo click → Destino.
- Clicks posteriores → Obstáculos.

### Mouse derecho

- Eliminar nodos.

### Teclas

- ESPACIO → Ejecutar algoritmo A*.
- C → Limpiar tablero.

## Instalación

```bash
pip install -r requirements.txt
```

## Ejecución

```bash
python main.py
```

## Tecnologías utilizadas

- Python
- Pygame

## Algoritmo implementado

- A* (A-Star)
