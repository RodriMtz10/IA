# Clasificador Fauna CNN

Proyecto desarrollado utilizando Redes Neuronales Convolucionales (CNN) para la clasificación automática de imágenes de animales.

## Clases reconocidas

* Ranas
* Pájaros
* Ballenas
* Changos
* Arañas

## Tecnologías utilizadas

* Python
* TensorFlow / Keras
* OpenCV
* NumPy
* Matplotlib
* Tkinter

## Entrenamiento

Para entrenar el modelo:

```bash
python entrenar.py
```

El modelo generado se almacena como:

```text
modelo_fauna.keras
```

## Clasificación

Para clasificar imágenes:

```bash
python clasificar.py
```

Se abrirá una ventana donde se podrá seleccionar una imagen para realizar la predicción.
